☕ Cold Open
Workplace agents have spent a year learning to call tools. Google’s latest move says the harder problem is deciding which calls count as legitimate. The winning integration is starting to look less like an API wrapper and more like a building with a front desk.
The Lead

Google puts a gate in front of workplace agents

Google has made its Workspace MCP servers and Workspace CLI generally available, then attached a migration clock: agentic tools must use MCP from 1 February 2027, while higher “Scaled” usage begins charging from 1 April. This is not just a new developer convenience. The managed path carries scoped sign-in, user confirmations, audit logs, DLP and administrator controls across Gmail, Drive, Calendar, Docs and more. Google says more than 99% of active developers remain within the standard tier; the real change is architectural. Builders who treated SaaS access as a private connector now have to treat identity, consent and usage limits as product constraints. Why it matters: agent capability is being packaged with a control plane, and that control plane will increasingly set the cost and pace of shipping.
THE TAKEAWAY
The new moat is not the ability to connect an agent to a system; it is the ability to make that connection governable at speed. Design the permission, evidence and spend path as deliberately as the prompt path—or inherit somebody else’s constraints later.

🧠 Builder’s Notebook
Observational equivalence: migrate behaviour, not just code
Intuition: two systems are observationally equivalent when the people and programs using them cannot tell which one is serving them in the situations that matter. It is a stage understudy test: the new actor may use different muscles backstage, but must hit the same cues under the lights.

Mechanism:

Application: compare status codes, fields, ordering, latency bounds and side effects—not just whether both paths return “success.” Anthropic’s Rust migration is the reminder that the undocumented edges are often the actual product contract. Try this (20 min): choose one workflow you plan to replace. List five observations a customer or integration could make, then write one replay fixture for each. The observation you cannot measure is the risk you have not priced.
🔧 Product Craft
Shadow mode is product discovery wearing a hard hat. When a team runs a new system beside the old one on real traffic, it is not merely testing correctness; it is learning what customers actually consider stable. The strongest migration dashboard compares outcomes by meaningful cohort—large customers, unusual payloads, retries, older SDKs—not a single pass rate. That framing changes release design. Do not ask, “Did the new architecture work?” Ask, “Which customer-visible promises did it preserve, and where did it make a new promise by accident?” A feature flag is therefore not just a rollback lever. It is a temporary research instrument for discovering your real interface contract.
